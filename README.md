# @framework/socialite

OAuth2 social authentication providers (GitHub, Google, Discord, and custom OIDC).

> **Read-only subtree split** — This package is developed inside the main [**mohamedhabibwork/framework**](https://github.com/mohamedhabibwork/framework/tree/main/packages/socialite) monorepo and automatically synced to [`mohamedhabibwork/framework-socialite`](https://github.com/mohamedhabibwork/framework-socialite). Please open issues and pull requests in the main framework repository.

## Installation

### Inside a Standalone App (via GitHub)

```json
{
  "dependencies": {
    "@framework/socialite": "github:mohamedhabibwork/framework-socialite"
  }
}
```

```sh
bun install
```

### Creating a New Application

Use the starter application template repository to bootstrap a full application with all framework packages pre-wired:

```sh
gh repo create my-api --template mohamedhabibwork/framework-app --clone
cd my-api
bun install
```
